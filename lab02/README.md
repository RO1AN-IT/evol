# Лабораторная работа № 2

Меню на неделю: целочисленный генетический алгоритм с ограничениями калорийности, стоимости и разнообразия.

Группа Б24-527, номер в группе N = 7. Индекс группы Q = 2, две цифры года Y = 26.

```text
V = 1 + ((17·7 + 7·2 + 26) mod 20) = 1 + (159 mod 20) = 20
```

Вариант 20: формирование меню на 7 дней. В каталоге 36 блюд, по 12 на завтрак, обед и ужин.

## Запуск

Нужны Python 3, NumPy и Matplotlib.

```bash
cd lab02
python3 -m pip install -r requirements.txt
python3 main.py
```

Команда проводит 20 запусков трёх настроек генетического алгоритма, 20 запусков случайного поиска с ремонтом и 20 жадных сборок. Таблицы и графики появляются в `results/`, каталог блюд — в `data/dishes.json`.

Зерно запуска `i` равно `base_seed + i` из `config.json`. Одно и то же зерно передаётся всем методам.

## Что лежит в каталоге

| Файл | Назначение |
| --- | --- |
| `config.json` | Вариант, ограничения и параметры алгоритма |
| `data/dishes.json` | 36 блюд: название, категория, ккал, цена |
| `src/` | Кодирование, операторы, ремонт, алгоритм |
| `report.md` | Отчёт |
| `results/runs.csv` | Итог каждого запуска |
| `results/summary.csv` | Сводка по методам |
| `results/best_menu.txt` | Лучшее меню таблицей |
| `results/examples.txt` | Два допустимых и два недопустимых меню |
| `results/figures/` | Графики и блок-схема |

Готовые пакеты эволюционной оптимизации не используются. Селекция, кроссовер, мутации и ремонт написаны в `src/`.
