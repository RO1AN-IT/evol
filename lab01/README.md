# Лабораторная работа № 1

Многомерная минимизация функции HGBat вещественным генетическим алгоритмом.

Группа Б24-527, номер в группе N = 7. Индекс группы Q = 2, две цифры года Y = 26.

```text
V = 1 + ((17·7 + 7·2 + 26) mod 20) = 1 + (159 mod 20) = 20
d = 5 + (20 mod 6) = 7
```

Вариант 20: функция HGBat на кубе [−15, 15]^7. Глобальный минимум равен 0 в точке (−1, …, −1).

## Запуск

Нужны Python 3, NumPy и Matplotlib.

```bash
cd lab01
python3 -m pip install -r requirements.txt
python3 main.py
```

Один запуск выполняет 20 независимых прогонов двух конфигураций генетического алгоритма, 20 прогонов случайного поиска с тем же бюджетом, локальные спуски для объяснения ландшафта и сохраняет таблицы и графики в `results/`.

Начальное зерно задано в `config.json` полем `base_seed`. Запуск с номером `i` (от 0 до 19) использует зерно `base_seed + i`. Одно и то же зерно передаётся всем трём методам.

## Что лежит в каталоге

| Файл | Назначение |
| --- | --- |
| `config.json` | Параметры варианта и эксперимента |
| `main.py` | Точка входа |
| `src/` | Функция, операторы, алгоритм, графики |
| `report.md` | Отчёт |
| `results/runs.csv` | Итог каждого запуска |
| `results/summary.csv` | Лучшее, среднее, медиана, СКО, худшее |
| `results/figures/` | Графики и блок-схема |

Готовые пакеты эволюционной оптимизации не используются. Селекция, SBX-кроссовер, гауссовская мутация и элитизм написаны в `src/operators.py` и `src/ga.py`.
